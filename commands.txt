start - Saluda al bot
asistencia - Envía una encuesta de asistencia semanal a la U

contador - Inicia un contador editable
sumar - Suma un número al contador (por defecto 1)
incrementar - Suma un número al contador (por defecto 1)
restar - Resta un número al contador (por defecto 1)
decrementar - Resta un número al contador (por defecto 1)

lista - Inicia una lista editable
listar - Inicia una lista editable
agregar - Agrega un ítem a la lista
quitar - Quita un ítem de la lista por número
editar - Edita un ítem de la lista por número
deslistar - Cierra una lista
cerrar - Cierra una lista

new_group - Crea un grupo de tags
group_add - Agrega un tag a un grupo
group_rm - Quita un tag de un grupo
rename_group - Renombra un grupo de tags
list_groups - Lista todos los grupos de tags
tag - Tagea a todos los miembros de un grupo
untag - Elimina el mensaje de tag respondido

slashear - Convierte una frase en formato camelCase con slash
uwuspeech - Convierte una frase al estilo uwu
repetir - Repite el texto de un mensaje
distancia - Cuenta la distancia en mensajes entre dos mensajes
